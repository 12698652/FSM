食品腐败预测系统 · 极简接线图

看这一张图就够了 · 每根线都标了颜色和接到哪里

红色 = 5V 电源
橙色 = 3.3V 电源
黑色 = GND 地线
蓝色 = SDA 数据
黄色 = SCL 时钟
绿色 = 模拟信号

每个元件接几根线?一看就懂

BME680 (温湿度+气压+VOC)

  • VCC ← 橙色线 ← ESP32 的 3V3 引脚
  • GND ← 黑色线 ← ESP32 的 GND 引脚
  • SDA ← 蓝色线 ← ESP32 的 GPIO21
  • SCL ← 黄色线 ← ESP32 的 GPIO22

SGP30 (TVOC + eCO₂)

  • VCC ← 橙色线 ← ESP32 的 3V3 引脚
  • GND ← 黑色线 ← ESP32 的 GND 引脚
  • SDA ← 蓝色线 ← ESP32 的 GPIO21
  • SCL ← 黄色线 ← ESP32 的 GPIO22
SDA/SCL 与 BME680 共用同一组线(并联)

MQ-137 (氨气传感器)

  • VCC ← 红色线 ← 5V 母线(注意是5V,不是3.3V!)
  • GND ← 黑色线 ← ESP32 的 GND 引脚
  • AO → 绿色线 → ESP32 的 GPIO34
⚠ VCC 必须接 5V!接 3.3V 加热器不工作

风扇 M1 (5V 小风扇)

  • +红线 ← 红色线 ← SW2 风扇开关 ← 5V 母线
  • -黑线 ← 黑色线 ← ESP32 的 GND 引脚
风扇红线接 SW2 中间脚,SW2 另一脚接 5V

ESP32 主控板(核心)

  • VIN ← 红色线 ← 5V 母线(主供电)
  • 3V3 → 橙色线 → BME680 + SGP30 的 VCC
  • GND → 黑色线 → 所有模块的 GND(共地)
  • GPIO21 → 蓝色线 → BME680 + SGP30 的 SDA
  • GPIO22 → 黄色线 → BME680 + SGP30 的 SCL
  • GPIO34 ← 绿色线 ← MQ-137 的 AO

5V/3A USB 充电头(电源)

  • 红线(+) → SW1 总开关 → 5V 母线
  • 黑线(-) → GND 母线(公共地)
用手机快充充电头即可,5V/3A 输出

📋 接线步骤(按顺序做,不会乱)

  1. 断电:USB 充电头先不要插插座,SW1/SW2 都拨到 OFF
  2. 接 ESP32 的电源:5V 充电头红线 → SW1 → ESP32 的 VIN;黑线 → ESP32 的 GND
  3. 接 BME680:4 根线 — VCC(橙→3V3)、GND(黑→GND)、SDA(蓝→GPIO21)、SCL(黄→GPIO22)
  4. 接 SGP30:4 根线 — 同 BME680,SDA/SCL 并联到同一组线上
  5. 接 MQ-137:3 根线 — VCC(红→5V母线,不是3V3!)、GND(黑)、AO(绿→GPIO34)
  6. 接风扇 M1:2 根线 — 红线 → SW2 → 5V母线;黑线 → GND
  7. 检查:用万用表测 5V 和 GND 之间,电阻应 >1kΩ(不能短路)
  8. 通电测试:插上充电头,SW1 拨到 ON,看到 ESP32 板载红灯亮起 = 成功!
💡 小贴士:
  • 所有 GND(地线)必须接在一起,叫"共地",这是电路工作的基础
  • SDA/SCL 是 I²C 总线,多个传感器可以并联到同一对线上(本项目 BME680 + SGP30 共用)
  • MQ-137 上电后会发热(正常现象),需要预热 1 分钟数据才稳定
  • ESP32 烧录程序时,单独用 USB-C 线接电脑,不要接 5V 充电头(避免双供电)
⚠ 重要提醒:
  • MQ-137 的 VCC 必须接 5V,绝对不能接 3.3V(否则加热器不工作)
  • BME680 和 SGP30 的 VCC 必须接 3.3V,不能接 5V(会烧坏)
  • 接线时一定要断电!确认所有线接对后再通电
