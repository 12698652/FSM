# PCB 手工核验清单（方式 B ｜ 万用表 + 目视）

> **适用对象**：食品腐败预测系统 主控板（80 mm × 60 mm，双层，FR-4）
> **依据**：工程文件 `FoodSpoilageMonitor.net`（16 元件 / 8 网络）+ `generate_kicad.py` + 上次烧板记录
> **总原则**：**先核 3 个已知疑点 → 再做全板通断 → 最后限流分级上电**。全程"先断电测量，再上电"。

---

## 0. 工具与安全（开工前）

| 项目 | 要求 |
|---|---|
| 万用表 | 至少支持 通断/二极管档、Ω 档、DCV 档 |
| 观察 | 放大镜或手机微距（看锡渣、细线） |
| 焊接 | 细锡线、助焊剂、镊子、无水酒精 + 无绒布 |
| 供电 | **直流稳压电源（带限流）**；退一步用 5V 电源串一个 12V/5W 灯泡限流 |
| 防静电 | 手环或先摸金属放静电 |
| ⚠️ 铁律 | **上电必须限流**；插拔任何模块**必须先断电** |

## 1. 三个已知疑点（先核这三个，决定后面怎么测）

### 疑点 1：总开关 / 保险丝可能没串进 +5V 通路
工程网表里 **`SW1` 第 2 脚、`F1` 第 2 脚没有连到任何网络（悬空）**。按这份网表，`J1` 的 +5V 直接上了母线，**开关和保险丝相当于"摆设"**——这也正好解释了上次 10 mil 细线为什么会被直接烧断、毫无保护。

**实测（断电，通断档）：**
- [ ] 测 `J1` 的 **+5V 脚 ↔ `C1` 正极**：
  - 期望：**必须经过 SW1 和 F1**，即开关拨到 OFF 时应**不通**。
  - 若**始终导通（与开关状态无关）→ 开关/保险丝被旁路，必须割线改接。**
- [ ] 测 `F1` 两个焊盘之间：冷态 PPTC 应导通（几 Ω 内）；**两端都不通 → 保险丝没串进去或已损坏**。
- [ ] 测 `SW1` 输入脚 ↔ 输出脚：拨 ON 通、拨 OFF 断。

### 疑点 2：MQ-137 的 AO 直接进 MCU，没有分压（烧 IO 风险）
网表 `NH3_AO` 网络把 `U4.AO` 直接接到 `U1` 的 ADC 脚，**中间没有任何电阻**。MQ-137 用 5V 供电时 AO 最高接近 5V，而 MCU 的 IO 只能吃 3.3V。

**处理**：AO → ADC 之间串 **10 kΩ**，再从 ADC 端到 GND 接 **20 kΩ**（分压到约 3.3V）。
- [ ] 断电，Ω 档测 `U4.AO` 焊盘 ↔ `U1` 的 ADC 焊盘之间：应有 **≈10 kΩ**，且 ADC 端对 GND 有 **≈20 kΩ**。
- [ ] 若两者**直通 0 Ω → 必须补分压再上电**，否则一接触高浓度气体就可能打坏 IO。

### 疑点 3：`U1` 的封装 / 引脚与实物是否一致（最容易踩）
工程文件里 `U1` 用的是 `NodeMCU-32S` 封装，符号只有 6 个脚（VIN/GND/3V3/GPIO21/GPIO22/GPIO34），是**简化占位**，不是真实模块引脚。而你实际用的是 **ESP32-S3-Nano**，与 ESP32-WROOM-32 / NodeMCU-32S 的**引脚定义完全不同**。

- [ ] 对实物丝印逐脚确认：**5V/VIN、GND、3V3、I²C 两根线、以及一根 ADC 可用脚**。
- [ ] **重点**：经典 ESP32 用的 **GPIO34**，在 **ESP32-S3 上不能做 ADC**（S3 的 ADC1 是 GPIO1–GPIO10，ADC2 是 GPIO11–GPIO20）。若固件仍按 GPIO34 读 MQ-137，会读到无效值，需要改脚。
  > 说明：S3 的 ADC 可用脚范围我这边只能给出通用结论，**最终请以你手上模块的官方引脚图为准**，我不替你臆断。
- [ ] 确认板上排母/焊盘与实物模块的**引脚间距、外形**能对上（2.54 mm）。

## 2. 目视检查（断电）

- [ ] 板面无锡渣、拉尖、铜箔起翘/划伤
- [ ] 过孔孔壁完整，无未金属化、无堵孔
- [ ] **+5V 主干线宽**：设计建议 ≥ 20 mil(0.5 mm)。找出 `J1/SW1/F1 → U1(VIN)` 以及喂给 `U4`(MQ-137) 的那条线；**若仍是 10 mil 细线 → 记为必改项**
- [ ] MQ-137 加热电流的走线**是否独立加粗、是否借道 `U3`(SGP30) 焊盘**（重点看，上次疑似问题点）
- [ ] I²C 两根线是否远离 MQ-137 加热走线
- [ ] 丝印位号清晰、元件方向标记可见

## 3. 八条网络连通性核验（断电，通断/蜂鸣档）

> 下表用**功能名**，引脚以**实物焊盘**为准（不要照抄网表的脚号）。每条逐点应"响"。

| # | 网络 | 应互相导通的测试点 | 期望 | 实测 | 结论 |
|---|---|---|---|---|---|
| 1 | +5V | `J1(+)` · `SW1` · `F1` · `C1(+)` · `U1(VIN)` · `U4(VCC)` · `SW2(进)` · `R1` · `TB1-1` | 全响 | | |
| 2 | GND | `J1(-)` · `C1(-)` · `C2` · `U1(GND)` · `U2/U3/U4(GND)` · `M1(-)` · `D1`(负极) · `TB1-2` · `TB2-4` · `TB3-2` | 全响 | | |
| 3 | +3V3 | `U1(3V3)` · `U2(VCC)` · `U3(VCC)` · `TB1-4` | 全响 | | |
| 4 | SDA | `U1` · `U2(SDA)` · `U3(SDA)` · `TB2-1` | 全响 | | |
| 5 | SCL | `U1` · `U2(SCL)` · `U3(SCL)` · `TB2-2` | 全响 | | |
| 6 | NH3_AO | `U4(AO)` · `U1(ADC)` · `C2` · `TB2-3` | 全响 | | |
| 7 | FAN_OUT | `SW2(出)` · `M1(+)` · `TB3-1` | 全响 | | |

## 4. 相邻网络短路检查（断电，通断/Ω 档）—— 必做

两两之间**都不应导通**（表针不动 / 显示 OL / 兆欧级）：

- [ ] +5V ↔ GND
- [ ] +3V3 ↔ GND
- [ ] +5V ↔ +3V3
- [ ] SDA ↔ SCL
- [ ] SDA ↔ GND ｜ SCL ↔ GND
- [ ] NH3_AO ↔ GND
- [ ] **NH3_AO ↔ +5V（重点）**：AO 走线靠近 +5V，最容易搭锡
- [ ] FAN_OUT ↔ GND ｜ FAN_OUT ↔ +5V

**任一"导通"→ 找到搭锡/短路点清掉，严禁上电。**

## 5. 上电前静态电阻（断电，Ω 档）＋正常值参照

| 测量点 | 本次实测 | 正常参照 | 判读 |
|---|---|---|---|
| 板 `+5V ↔ GND` | ______ kΩ | 约 11 kΩ | < 100 Ω → 严禁上电 |
| 板 `+3V3 ↔ GND` | ______ kΩ | kΩ 级以上 | 明显偏低 → 查短路 |
| `U4`(MQ-137) `VCC ↔ GND` | ______ Ω | **约 31–37 Ω** | 这是**加热丝阻值，正常**，不是短路 |
| `U3`(SGP30) `VIN ↔ GND` | ______ kΩ | 约 96 kΩ | 明显偏低 → 查 |

## 6. 分级上电测试（务必限流，一步一停）

- [ ] 电源**限流 100 mA**，电压从 **0 V 缓慢升到 5 V**
- [ ] **空载电流**（不插传感器、风扇关）：应 **< 约 20 mA**（仅 LED）；若一上电就顶到限流值 → 立刻断电查短路
- [ ] 测 +5V 实际值：**4.9–5.1 V**
- [ ] 测 +3V3 实际值：**3.25–3.35 V**
- [ ] 测温：MQ-137 发微热属正常（加热器 ~0.9 W）；**`U3`、`U1` 异常发烫立即断电**
- [ ] **逐路插模块，每次先断电**：先 `U2`(BME680) → 扫 I²C 见 `0x76` → 再 `U3`(SGP30) 见 `0x58` → 最后 `U4`(MQ-137)
- [ ] 上电后先等 MQ-137 **预热 1–2 分钟**再看读数
