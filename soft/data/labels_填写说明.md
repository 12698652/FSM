# labels_work.csv 填写说明（简明版）

## 一句话说清

**传感器的数据（温度/气体/NH₃）设备自动记录，你不用管。你只需要填一列：`stage`——凭你自己的眼睛和鼻子判断当时食品新不新鲜。**

## 怎么判断 stage（感官评价法）

打开舱盖，看一眼、闻一下，对照下表打分：

| stage | 含义 | 判断标准 |
|---|---|---|
| **0** | 新鲜 | 正常色泽、正常气味（奶香味） |
| **1** | 预警 | 颜色略发暗/表面略发黏/气味开始变淡或有轻微异味 |
| **2** | 危险 | 明显酸臭/结块分层/明显发黏变色 |

判断不了就留空，宁可少填不要瞎填。

## 具体操作（针对当前牛奶/酸奶实验）

1. 用 **Excel 打开 `data\labels_work.csv`**（已是带 BOM 的 UTF-8，直接打开中文正常）。
2. 表里 27 行，每行 `note` 列我已标好当时舱里是什么：
   - `牛奶(鲜)在舱` —— 25日晚~26日下午那批
   - `酸奶(鲜)在舱` —— 26日~27日那批
   - `酸奶(隔日回舱)` —— 27日21:30放回的
   - `空舱(无样品,可删行)` —— **这些行直接删掉**，没食品就没标签
3. 每行只填 `stage` 一列（0/1/2）。`tvb_n`、`ph` 两列**没有实验条件就不用填**（那是实验室测挥发性盐基氮用的，科创阶段用感官评价完全够）。
4. 凭回忆填不了的行（比如凌晨的）就留空或删掉——**只填你真正观察过的**。
5. 填完**另存为** `data\labels.csv`。

## 三条红线（为什么不能自动填）

1. **绝对不要**用板子的 NH₃/CO₂ 读数去推 stage——那叫循环论证，模型会"假装很准"（旧版假模型 97.88% 就是这么来的）。
2. 标签必须来自**你自己的独立观察**，和传感器无关。
3. 时间格式保持 `YYYY-MM-DD HH:MM:SS`，改坏了这行会被静默丢弃。

## 以后做实验的固定流程（建议）

1. 放入食品前，在便签/手机记一笔：**时间 + 什么食品**（告诉我一声也行，我帮你标到 note 列）。
2. 实验期间**每隔 2~4 小时开盖观察一次**，记：时间 + 0/1/2。
3. 取出食品时再记一笔。
4. 实验结束后把观察记录填进 labels_work.csv（或直接发我，我帮你填）。

> 原则：**观察几次就填几行**，一次实验有 5~10 个真实标签点就很够用了。
