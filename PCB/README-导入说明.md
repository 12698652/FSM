# 食品腐败风险预测系统 - PCB工程文件导入说明

## 生成的文件清单

| 文件名 | 说明 |
|---|---|
| `FoodSpoilageMonitor.pro` | KiCad 5 工程文件 |
| `FoodSpoilageMonitor.sch` | 原理图(简化版,需在EDA里完善连线) |
| `FoodSpoilageMonitor.kicad_pcb` | PCB布局文件(含板框+元件位置+网络) |
| `FoodSpoilageMonitor.net` | 网表文件(16元件/8网络,备份用) |
| `FoodSpoilageMonitor.lib` | ESP32自定义符号库 |
| `FoodSpoilageMonitor.dcm` | 符号库描述文件 |
| `BOM清单.csv` | 物料清单(含嘉立创物料编号参考) |
| `generate_kicad.py` | Python生成脚本(如需修改可重新运行) |

---

## 方法一:导入整个KiCad工程(推荐)

### 步骤

1. **打开嘉立创EDA专业版**

2. **导入工程**:
   - 顶部菜单: `文件` → `导入` → `KiCad工程`
   - 选择 `FoodSpoilageMonitor.pro` 文件
   - 等待导入完成(会自动生成原理图和PCB)

3. **检查原理图**:
   - 打开 `FoodSpoilageMonitor.sch`
   - 检查元件是否都在(应该有16个元件)
   - **重要**: 原理图里的连线可能不完整,需要手动连线
   - 可参考网表文件 `FoodSpoilageMonitor.net` 确认连接关系

4. **检查PCB**:
   - 打开 `FoodSpoilageMonitor.kicad_pcb`
   - 应该看到 80mm × 60mm 的板框
   - 4个角的M3安装孔
   - 16个元件已摆放到位
   - 元件之间有飞线(airwire)提示连接关系

5. **更新封装为嘉立创物料**:
   - 双击每个元件 → 在属性里搜索嘉立创物料编号
   - 这样可以直接下单SMT贴片
   - 物料编号见 `BOM清单.csv`

6. **布线**:
   - 使用嘉立创EDA的自动布线或手动布线
   - 飞线会指导你连接哪些焊盘
   - 建议电源线用 20mil,信号线用 12mil

7. **铺铜和检查**:
   - 顶层和底层都铺GND地铜
   - 运行DRC检查(设计规则检查)
   - 确认无错误后导出Gerber

8. **下单**:
   - `制造` → `PCB订单`
   - 嘉立创会自动生成Gerber文件
   - 选择板厚1.6mm,双层板,数量按需

---

## 方法二:只导入网表(如果方法一有问题)

### 步骤

1. **在嘉立创EDA里新建工程**:
   - `文件` → `新建` → `项目`
   - 命名 `FoodSpoilageMonitor`

2. **新建原理图**:
   - 添加元件(从嘉立创元件库搜索)
   - 物料编号见 `BOM清单.csv`

3. **导入网表连接**:
   - 原理图编辑器 → `工具` → `从网表导入`
   - 选择 `FoodSpoilageMonitor.net`
   - 自动生成连线关系

4. **转PCB**:
   - 原理图 → `设计` → `更新PCB`
   - 元件会带网络关系进入PCB

5. **摆放元件**:
   - 参考 `FoodSpoilageMonitor.kicad_pcb` 里的位置
   - 或按你的喜好重新摆放

## PCB布局说明

### 板子参数
- **尺寸**: 80mm × 60mm
- **层数**: 2层(顶层 + 底层)
- **板厚**: 1.6mm
- **材质**: FR-4
- **安装孔**: 4× M3(距边5mm)

## 网络连接关系(8个网络)

### Net 1: +5V (5V电源母线)
```
J1.1 → SW1.1 → F1.1 → C1.1
                     → U1.1 (ESP32 VIN)
                     → U4.1 (MQ-137 VCC)
                     → SW2.1 (风扇开关输入)
                     → R1.1 (LED限流电阻)
                     → TB1.1
```

### Net 2: GND (公共地)
```
J1.2 → C1.2 → C2.2
            → U1.2 (ESP32 GND)
            → U2.2, U3.2, U4.2 (所有传感器GND)
            → M1.2 (风扇GND)
            → D1.1 (LED负极)
            → TB1.2, TB2.4, TB3.2
```

### Net 3: +3V3 (3.3V电源)
```
U1.3 (ESP32 3V3输出)
  → U2.1 (BME680 VCC)
  → U3.1 (SGP30 VCC)
  → TB1.4
```

### Net 4: SDA (I²C 数据线)
```
U1.4 (GPIO21) → U2.3 (BME680 SDA) → U3.3 (SGP30 SDA) → TB2.1
```

### Net 5: SCL (I²C 时钟线)
```
U1.5 (GPIO22) → U2.4 (BME680 SCL) → U3.4 (SGP30 SCL) → TB2.2
```

### Net 6: NH3_AO (氨气模拟信号)
```
U4.3 (MQ-137 AO) → U1.6 (GPIO34) → C2.1 (滤波电容) → TB2.3
```

### Net 7: FAN_OUT (风扇供电)
```
SW2.2 (开关输出) → M1.1 (风扇+) → TB3.1
```

### Net 8: LED_A (LED驱动)
```
R1.2 (电阻输出) → D1.2 (LED正极)
```

## 注意事项

### 导入后必做的检查

1. **原理图连线**: 生成器产出的原理图连线是简化的,导入后请根据网表 `.net` 文件确认/补全连线
2. **封装验证**: 导入后逐个检查元件封装是否正确,特别是:
   - ESP32 模块的实际尺寸是否匹配
   - 端子排的引脚间距是否为 5.08mm
   - MQ-137 模块的实际引脚排布
3. **DRC检查**: 布线完成后务必运行设计规则检查(DRC)
4. **3D预览**: 用嘉立创EDA的3D视图检查元件是否有冲突

### 关于ESP32模块

本项目 ESP32 使用 **NodeMCU-32S 开发板**封装(带排针的成品板),直接插到PCB的排母上。
如果你用的是裸 ESP32-WROOM-32 模块,需要改用 `RF_Module:ESP32-WROOM-32` 封装。

### 如需修改

如果元件位置、网络连接或封装需要修改,编辑 `generate_kicad.py` 脚本后重新运行:

```powershell
cd "c:\Users\Administrator\Desktop\FSM\PCB"
python generate_kicad.py
```

脚本里的关键修改点:
- `COMPONENTS`: 元件清单和原理图坐标
- `NETS`: 网络连接关系
- `gen_pcb()` 里的 `pcb_components`: PCB上的元件位置和封装
- `gen_bom()`: BOM物料清单
